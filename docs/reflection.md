# Reflection — Lab 03

## 1. สิ่งที่เปลี่ยนจาก Lab 02

Lab 02 มีเฉพาะ Voltage Divider Lab 03 เพิ่ม Fixed Bias และ Emitter Bias โดยเลือกโหมดจาก dropdown แล้วกด **แสดงฟอร์มโหมดนี้** หน้าเว็บจะโหลดใหม่ด้วย `GET /?mode=...` และแสดงเฉพาะช่องที่โหมดนั้นใช้ ไม่มีการเขียน JavaScript เพื่อคำนวณ เพื่อให้ค่าบนหน้าเว็บมาจาก Python เพียงทางเดียว

## 2. ทำไมสมการต้องอยู่ใน `dc_bias.py` คนเดียว

`app.py` มีหน้าที่อ่านฟอร์ม แปลง kΩ → Ω เรียกฟังก์ชันที่ตรงกับโหมด และส่ง `BiasResult.to_dict()` ให้ template แสดงผล ถ้าเขียนสมการซ้ำใน template หรือใน route ค่าที่เห็นกับค่าที่คำนวณจะตรงกันไม่ได้โดยอัตโนมัติ การแยกนี้ทำให้เทสต์วิศวกรรมเรียกสมการตรง ๆ ได้โดยไม่ต้องรันเว็บ และการแก้ region/warning ทำได้ที่เดียว

## 3. ตรวจสมการด้วยค่ามืออย่างไร

คำนวณ A2 และ A3 จากสมการในใบงานด้วยมือก่อน (ดูรายละเอียดและหน่วยใน `docs/validation.md` หมวดค่าอ้างอิงอิสระ) ได้ A2: IB 11.300 µA, IC 1.1300 mA, VCE 9.5140 V; A3: IB 10.2634 µA, IC 1.0263 mA, VCE 8.7054 V แล้วค่อยเทียบกับค่าที่เว็บแสดง เทสต์ยังยืนยันว่า A1 Divider ยังได้ IC 1.230 mA / VCE 8.052 V เท่า Lab 02 ทุกหลัก

## 4. ทำไมต้องตรวจจากเบราว์เซอร์จริงและต้องระบุวิธี

HTTP test พิสูจน์ว่า server ตอบถูก แต่ไม่ได้พิสูจน์ว่าฟอร์มส่งชื่อ/หน่วย/โหมดถูกต้องหรือไม่ การกรอกจริงในเบราว์เซอร์จึงตรวจทั้ง chain ตั้งแต่ input → form post → route → สมการ → ผลลัพธ์ ใบงานให้คะแนนเท่ากันทุกวิธีแต่ต้องบอกความจริง: รอบนี้ใช้ **OpenCode Browser** เพราะ Playwright MCP ยังไม่โหลดใน session ที่ตรวจ จึงบันทึกชื่อวิธีและเหตุผลไว้ในตาราง A1–A5 แทนการอ้างว่าใช้ MCP

## 5. คำถามปิด Lab: เปลี่ยน RE แล้วผลไม่เปลี่ยน จะตรวจอย่างไร?

1. ดูค่าที่ส่งออกจากฟอร์มก่อน — ตรวจว่า input `re`, `mode` และ `r_unit` ใน request มีค่าที่เปลี่ยนจริง (เช่น A3 RE=1 → A4 RE=2) ผ่าน Developer Tools → Network หรือข้อความที่ render กลับมาหลัง error
2. ตามเข้า `app.py` ว่าค่า RE ถูกคูณ `scale` ครั้งเดียวและส่งเข้าฟังก์ชันที่ถูกต้อง (`calculate_emitter` ไม่ใช่ `calculate_divider`)
3. เรียก `calculate_emitter(...)` โดยตรงด้วยค่า SI ที่ตั้งใจ แล้วเทียบผลกับหน้าเว็บ ถ้าฟังก์ชันตรงถูกแต่หน้าเว็บไม่เปลี่ยน แปลว่าปัญหาอยู่ที่ form/route ไม่ใช่สมการ
4. เขียนเทสต์ regression ที่เปลี่ยน RE เพียงตัวเดียวแล้ว assert ว่า IC และ VCE เปลี่ยนตามค่ามือ (มีอยู่แล้วใน `test_dc_bias.EmitterBiasTests.test_larger_re_lowers_ic` และ `test_web.ModeCalculateTests.test_larger_re_changes_the_result`)
